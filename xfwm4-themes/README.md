# XFWM4 Window Themes

**xfwm4-themes** for the [XFCE Window Manager](https://wiki.archlinux.org/index.php/Xfwm).

## Installation

```sh
cd xfwm4-themes && ./install.sh
```

Or manually: unzip `.7z` files and copy folders to `/usr/share/themes/` or `~/.themes/`.
